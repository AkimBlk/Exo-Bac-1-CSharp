# Démineur

Projet réalisé en première année d'études en informatique.

## Description

Développement d'un jeu de Démineur en **C# avec Windows Forms**.

Le projet permet de générer une grille de jeu, de placer aléatoirement les mines, de calculer le nombre de mines présentes autour de chaque case et de révéler les cases vides.

## Technologies

- C#
- Windows Forms

## Fonctionnalités

- Génération d'une grille de jeu
- Placement aléatoire des mines
- Calcul des mines adjacentes
- Révélation des cases
- Révélation automatique des zones vides
- Détection des mines
- Possibilité de recommencer une partie
